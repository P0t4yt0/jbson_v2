User Management

Control who has access to your system, create new accounts for your employees, and monitor every action taken inside the software.

System Users & Accounts

User Accounts: View all registered users, manage their access levels, and approve new account requests.

Account Lists

System Users Table

Shows everyone who currently has access to the system. You can see their Full Name, Username, Role (e.g., ADMIN or EMPLOYEE), and the date their account was created.

Action Buttons

Use the pencil icon to edit a user's details, or the red trash can icon to delete their account and remove their access. Note: You cannot delete your own account, marked as "(You)".

Pending Account Requests

If employees can request accounts, their requests will appear in this bottom table waiting for an Admin's approval before they can log in.

Register New Account Form

Use the form on the right side of the screen to manually add a new worker to the system.

1. Basic Details

Type the user's Full Name and let them choose a unique Username for logging in.

2. System Role

Select their access level. Choose "Employee" for normal staff, or "Admin" if they need full access to reports and settings.

3. Secure Password

Create a strong password. The system requires it to have at least 8 characters, 1 uppercase letter, and 1 number. A checklist will turn green as you meet these rules.

Activity Logs & Audit Trail

System Monitoring: Track every single action done by your users so you always know who did what and when it happened.

Log Filters

If you are looking for a specific event, use the search tools at the top of the page.

Search Bar

Type a username (like "JBSON") or an action (like "logged in") to instantly find matching records.

Date Filter

Select a start and end date to only view actions that happened during that specific time period.

Role & Action Filters

Use the dropdowns to only show actions done by Admins, or specifically look for "Edits" or "Deletions". Click the Filter button to apply.

Reading the Activity Logs

The main table records the exact history of your system. Here is how to understand the data:

Basic Logs (#AUTH / #ACT)

These show general actions like a user logging in successfully, generating a new barcode, or creating a new Purchase Order. It shows the exact Date and Time it occurred.

System Audits (#AUD)

When the "User" is labeled as System, it means it is a detailed background record of an action that just happened.

Before and After Values

If someone changes data (labeled with a yellow EDIT tag), the log will show exactly what was changed. For example, it will display the old stock number in red, an arrow, and the new stock number in green (e.g., SafetyStock: 0 ➔ 7).
